pyhotpants documentation
========================

**Version 0.3.0rc1** — audit release candidate

``pyhotpants`` wraps A. Becker's HOTPANTS image-subtraction code and provides
an optional Python/Numba backend, oversampled templates and connected-region
stamps. The C extension remains the default. See :ref:`compatibility` for the
numerical changes in this candidate; it has not yet been archived or released.
